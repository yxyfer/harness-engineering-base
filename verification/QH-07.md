## Implementation and ownership

Format is a thin delegate: CLI, environment, optional project format command,
package format script, then project-local Ruff/Prettier. It does not fix lint or
types. Check runs policies then one reviewed command/aggregate script, a complete
format:check/lint/typecheck trio, or required local native defaults. Missing
Ruff/Pyright/Prettier/ESLint/TypeScript cannot yield degraded success. Shell and
Markdown policy tools are required. Existing managers and native settings retain
authority; optional format is compatible with unchanged schema 1/2 config.

New opt-in templates ship native config and reviewed locks, not an installer.
Existing JS fixture pins are preserved. Typed ESLint uses a separate compatible
TypeScript 6.0.3 pin; its declared range excludes the existing fixture's 7.0.2.
Defaults use strict types and native runtime-boundary/import rules. No regex
linter, general policy DSL, hard source-size gate or Step 08 verifier was added.

Application native ignores exclude installed machinery. The authoring CI covers
that machinery explicitly and prunes runtime environments before enumeration.
Installed-copy tests fingerprint shipped bytes across formatting. Manifest
authoring includes only reviewed new inputs; no consumer conflicts are repaired.

Python Pyright uses its project-local bundled native executable and an installed
Node runtime, avoiding the Python wrapper's update query/runtime bootstrap.
Missing Node fails. Project commands can retain equivalent tools but own their
scope and must be non-mutating; arbitrary shell bodies are not semantically
validated. Defaults never request autofixes in check mode.

with a regression also requiring maintained domain source to remain selected.
Installed-copy testing exposed managed shell files needing authoring-only scope.
Consumer standards now check project shell, while explicit CI checks managed
shell. Native ignores protect managed Python/JS from application format.

Initial smoke failed EPERM binding loopback in the sandbox; the authorised retry
passed and both attempts are retained. The first 103-case aggregate run failed
two assertions, before final fixes; it is not presented as successful evidence.
An intermediate 105-case application run passed, then its self-test exposed
generated pytest cache copying after a manual native-template test. Copies now
prune caches and profile detection ignores runtime cache directories. A cache
regression preserves Python-only applicability; failed attempts remain retained.
A malformed command table also has a specific configuration-error regression.
Size guidance stayed advisory; the grouped fixture file rationale is TD-001.
