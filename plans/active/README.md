# Active Plans

The current delivery plan is
[Application quality harness implementation plan](QUALITY_FIRST_HARNESS.md). It
contains 19 ordered steps, a copy-ready prompt for each step, dependencies,
acceptance criteria and evidence requirements. Execute one step at a time. The
[previous roadmap](PROJECT_HARNESS_V2.md) retains completed-phase history; its
remaining sequence is superseded.

Create each bounded implementation effort from `../PLAN_TEMPLATE.md`. A plan
coordinates outcomes, implementation slices or linked tasks, dependencies,
risks, decisions, rollout, and verification.

Update the plan as facts change. When all acceptance criteria are evidenced, add
the verification report link and move the plan unchanged to `../completed/`.
