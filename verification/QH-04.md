[Preservation capture](qh-04-preservation.json) records the exact inventory

The verifier requires an inventory. Older kits need an explicit reviewed
inventory/verifier/metadata update; no installer or migration was added.
`generate-release` is release authoring, not a consumer repair command.
Metadata is editable and unsigned. Symlink checks assume a stable filesystem
and do not defend against concurrent replacement. Unlisted runtime/project
symlinks remain permitted; listed paths must be regular files without linked
parents. Canonical path validation precedes filesystem access to listed paths.

Implementation consulted Python's official
[pathlib documentation](https://docs.python.org/3/library/pathlib.html) for
normalisation and symlink behaviour and
[JSON documentation](https://docs.python.org/3/library/json.html) for duplicate
key detection using `object_pairs_hook`. No additional dependency was added.
