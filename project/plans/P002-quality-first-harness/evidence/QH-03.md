## Implemented contract and compatibility

- `source_paths.py` shares discovery for standards, documentation, claim scans
  and degraded Python syntax validation. It replaces their separate scan lists;
  it does not change the managed ownership walker reserved for Step 04.
- Exclusions are literal directories. `generated` matches that directory at any
  depth; `src/generated` matches only its root-relative prefix. Trailing slashes
  are optional. Similar siblings and files with those names remain in scope.
  Ignored directories are pruned before opening them.
- File and directory symlinks are skipped, including internal and cyclic links.
  Canonical policy inputs reject symlink components independently of exclusions.
  This is a conservative analysis boundary, not a runtime sandbox or defence
  against concurrent filesystem replacement. Native commands retain their own
  filesystem scope and permissions.
- Known suffixes retain their language. Extensionless executable direct, `env`
  and `env -S` shebangs recognise `python`, `python3`, versioned Python 3, and
  `sh`/`bash`/`dash`. Unknown interpreters, complex env prefixes and
  non-executable
  extensionless files are not guessed as shell. Other interpreters require
  deliberate native coverage. Extensionless Python receives size analysis and
  participates in the degraded syntax fallback.
- Mandatory policies run first. Project resolution retains CLI > environment >
  config > package `check` > package `lint`/`typecheck` > automatic Python.
  The package fallback runs each declared script once. Any selected override or
  package implementation prevents an additional Python stage. Policy and
  project failures still block with their observed exits.
- Native Ruff, Pyright, package scripts and Markdown lint retain their native
  scope/configuration. Harness exclusions are not forwarded as extra native
  ignore flags or a filtered native file list. Shell tools receive correctly
  classified harness file argv with spaces preserved. Markdown local-link
  checking supports angle-bracket destinations containing spaces.

Schema 1, version 0.1.0, override precedence, project-owned configuration and
explicit unittest behaviour remain unchanged. Consumers must update all managed
inputs together; checks now require the shared helper. Projects relying on
internal symlink analysis or guessed shell interpreters need deliberate native
coverage. [ADR-005](../../../../docs/DECISIONS.md) records the durable choice.
